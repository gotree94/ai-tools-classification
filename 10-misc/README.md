# 10. 기타 / 성격이 다른 항목

분류가 애매하거나 다른 카테고리와 성격이 다른 항목입니다.

## 항목

| 도구 | 메모 | 문서 |
|---|---|---|
| AnyPS5 | PS5 실행 파일 포팅 도구 → 원래 6번에 있으나 "기타"로 옮길 수 있음 | [../06-dev-hardware-re/anyps5.md](../06-dev-hardware-re/anyps5.md) |

## 확인 필요 항목 요약
조사 결과, 원본에서 "확인 필요"로 표시된 항목들은 모두 정상 저장소로 확인되었습니다.

- **Archify** → 아키텍처 다이어그램 스킬 ([../01-design-uiux/archify.md](../01-design-uiux/archify.md))
- **Orca** → 병렬 에이전트 데스크톱 오케스트레이터 ([../03-agent-runtime/orca.md](../03-agent-runtime/orca.md))
- **DSH Desktop** → DeepSeek Harness 데스크톱 클라이언트 ([../03-agent-runtime/dsh-desktop.md](../03-agent-runtime/dsh-desktop.md))
- **Ponytail** → "게으른 시니어" 프롬프트 스킬 ([../03-agent-runtime/ponytail.md](../03-agent-runtime/ponytail.md))
- **AnyPS5** → PS5 → PC 포팅 도구 ([../06-dev-hardware-re/anyps5.md](../06-dev-hardware-re/anyps5.md))

## 이름이 모호했던 항목 보정
- **text-to-cad**: 요청의 `OpenBMB/Text2CAD`는 404 → 실제 활성 프로젝트는 `earthtojake/text-to-cad`
- **REA**: URL 미지정 → `morluto/rea` 확인
- **e2e**: 단일 도구가 아니라 개념 → Playwright 중심으로 정리
- **ai-memory**: 동명 저장소 2개(akitaonrails / alphaonedev) 구분 필요
