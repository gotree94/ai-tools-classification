# Flutter

## 개요
단일 Dart 코드베이스로 모바일·웹·데스크톱 멀티플랫폼 앱을 만드는 **Google의 오픈소스 UI
툴킷**입니다(최신 3.47).

- 사이트: https://flutter.dev

## 설치
공식 설치 가이드(OS별 SDK)를 따릅니다.

- https://docs.flutter.dev/get-started/install

설치 후 환경 점검:
```bash
flutter doctor
```
VS Code 확장 또는 Android Studio 플러그인을 함께 사용합니다.

## 사용법
```bash
flutter create my_app
cd my_app
flutter run
```

## opencode 연동
CLI 기반이므로 opencode에서 셸 도구로 직접 실행합니다.
```
"flutter create로 새 앱을 만들고 웹에서 실행해줘"
```
`AGENTS.md`에 프로젝트 규칙(Dart 스타일·디렉터리 구조)을 적어두면 코드 생성 품질이 올라갑니다.
