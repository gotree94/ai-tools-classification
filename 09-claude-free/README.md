# 9. Claude 무료 계정으로 가능한 것

원본 목록의 9번 항목은 비어 있었습니다. 아래는 Claude 무료 계정에서 가능한 기능 정리입니다.
(정책은 변경될 수 있으므로 최신 정보는 Claude 공식 문서를 확인하세요.)

## 분류별 정리

| 분류 | 항목 |
|---|---|
| 생성·산출물 | 파일 만들기, 아티팩트(Artifacts) |
| 확장 기능 | 스킬, 커넥터 |
| 작업 관리 | 프로젝트, 메모리 |
| 정보·실행 | 웹검색, 코드 실행 |
| 사용 환경 | 웹 / PC / 폰 앱 |

## 각 항목 설명

### 생성·산출물
- **파일 만들기**: 문서·코드 등 산출물 생성
- **아티팩트(Artifacts)**: 대화창 옆에 렌더되는 실행 가능한 결과물(HTML/React/SVG 등)

### 확장 기능
- **스킬**: 반복 작업을 지침으로 정의해 재사용
- **커넥터**: 외부 서비스 연결(플랜에 따라 제한)

### 작업 관리
- **프로젝트**: 관련 대화와 자료를 묶어 관리
- **메모리**: 사용자 선호/맥락을 기억

### 정보·실행
- **웹검색**: 최신 정보 검색
- **코드 실행**: 분석/계산을 위한 코드 실행

### 사용 환경
- 웹 브라우저, PC 앱, 모바일 앱

## opencode와의 관계
이 항목들은 Claude 제품 기능이며, opencode는 별도 도구입니다.
Claude의 "스킬"(SKILL.md) 형식은 **opencode와 호환**되므로, Claude용 스킬을 opencode에서
그대로 쓸 수 있습니다. [../OPENCODE.md](../OPENCODE.md) 참고.
