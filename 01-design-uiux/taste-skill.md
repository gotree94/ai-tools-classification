# Taste Skill

## 개요
에이전트에게 **미적 판단(취향)** 을 부여하는 스킬입니다. "예쁘게 만들어" 수준의 모호한 요청을
구체적이고 일관된 디자인 결정으로 바꿔줍니다.

- 저장소: https://github.com/Leonxlnx/taste-skill

## 설치

### 스킬 단독 설치
```bash
npx skills add Leonxlnx/taste-skill
```

### Claude Code 플러그인
```bash
/plugin marketplace add Leonxlnx/taste-skill
/plugin install taste-skill
```

## 사용법
```
"이 대시보드 디자인을 좀 더 세련되게 다듬어줘"
"지금 UI의 시각적 위계를 개선해줘"
```

## opencode 연동
```bash
git clone --depth 1 https://github.com/Leonxlnx/taste-skill
```
생성된 `SKILL.md` 디렉터리를 `~/.config/opencode/skills/taste-skill/`로 복사합니다.
