# Emil Kowalski Skills

## 개요
디자이너/엔지니어 Emil Kowalski의 **애니메이션·인터랙션** 중심 스킬 모음(총 15종).
인터랙션 디테일, 성능, 프로토타이핑에 강합니다.

- 저장소: https://github.com/emilkowalski/skills

## 포함된 대표 스킬
`animate-expo`, `find-animation-opportunities`, `animation-performance`,
`animation-vocabulary`, `ask-sonner`, `prototype`, `mobile-native`, `break-ui` 등 15종.

## 설치

### 스킬 단독 설치
```bash
npx skills add emilkowalski/skills
```

### Claude Code 플러그인
```bash
/plugin marketplace add emilkowalski/skills
/plugin install emil-kowalski-skills
```

## 사용법
```
"이 모달에 적절한 등장 애니메이션을 추가해줘"
"애니메이션 성능을 점검하고 프레임 드랍을 줄여줘"
"이 화면에서 애니메이션이 들어갈 만한 곳을 찾아줘"
```

## opencode 연동
스킬 폴더를 전역 스킬 경로에 복사:
```bash
git clone --depth 1 https://github.com/emilkowalski/skills
xcopy /E /I skills\<skill-name> %USERPROFILE%\.config\opencode\skills\<skill-name>
```
