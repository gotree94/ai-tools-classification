# Hallmark

## 개요
프론트엔드 **품질(QA/디자인 검수)** 을 목표로 하는 스킬입니다. UI의 완성도, 일관성,
디테일을 점검하고 개선합니다.

- 저장소: https://github.com/Nutlope/hallmark

## 설치

### 스킬 단독 설치
```bash
npx skills add Nutlope/hallmark
```

### Claude Code 플러그인
```bash
/plugin marketplace add Nutlope/hallmark
/plugin install hallmark
```

## 사용법
```
"이 페이지를 hallmark 기준으로 검수해줘"
"UI의 일관성 문제를 목록으로 뽑아줘"
```

## opencode 연동
스킬 폴더를 `~/.config/opencode/skills/hallmark/`로 복사합니다.

```bash
git clone --depth 1 https://github.com/Nutlope/hallmark
```
