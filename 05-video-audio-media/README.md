# 5. 영상 / 음성 / 미디어 제작

영상·음성·디자인 미디어를 생성·편집하는 도구입니다.

## 도구 목록

| 도구 | 한 줄 요약 | 문서 |
|---|---|---|
| HyperFrames | HTML/CSS → 결정론적 MP4 렌더(에이전트용) | [hyperframes.md](./hyperframes.md) |
| MoneyPrinterTurbo | 주제 한 줄로 숏폼 영상 자동 생성 | [moneyprinterturbo.md](./moneyprinterturbo.md) |
| watermarks-remover | AI 워터마크/출처 표시 제거 | [watermarks-remover.md](./watermarks-remover.md) |
| ElevenLabs | AI 음성 합성·클로닝·더빙 | [elevenlabs.md](./elevenlabs.md) |
| Higgsfield | 다중 모델 영상 AI 플랫폼 | [higgsfield.md](./higgsfield.md) |
| Canva | 템플릿 기반 디자인/미디어 SaaS | [canva.md](./canva.md) |

## opencode 연동 요약
- **HyperFrames**: 스탠드얼론 스킬로 opencode에 설치 가능(`npx skills add`).
- **Higgsfield**: MCP 제공 → opencode MCP 등록 가능.
- 나머지는 CLI/API/웹 SaaS로 셸 도구·스크립트를 통해 호출합니다.
- 자세한 내용은 [../OPENCODE.md](../OPENCODE.md) 참고.
