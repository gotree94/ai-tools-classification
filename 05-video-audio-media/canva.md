# Canva

## 개요
템플릿 기반 **온라인 그래픽·디자인·영상 제작 SaaS**입니다. 프레젠테이션/소셜 이미지/영상 등을
드래그앤드롭으로 제작합니다.

- 사이트: https://www.canva.com

## 설치
웹 SaaS(`canva.com`) + Android/iOS 앱 → **설치 불필요**

## 사용법
1. 계정 생성
2. 템플릿 선택
3. 드래그앤드롭 편집
4. 다운로드 / 공유

## 무료 티어
- 무료 플랜: 기본 템플릿·기능 제공(일부 Canva 워터마크 포함)
- Canva Pro 등 유료 플랜: 프리미엄 자산·브랜드 킷 확대

## opencode 연동
Canva는 공개 MCP/CLI가 일반적이지 않아 자동 연동은 제한적입니다.
- Canva 앱/웹에서 직접 작업하거나,
- **Canva Connect API**를 스크립트로 호출해 opencode 셸 도구에서 사용합니다.
